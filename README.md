# Forever Hub

Forever Hub is a knowledge base for World of Warcraft: Forever: Classic levels 1–60, plus custom content such as the Skyborne race, Zephras Isle, custom campfires, and new dungeons and raids.

## Intended stack

- Next.js and React for the frontend
- Node.js and Express for the API
- PostgreSQL or SQLite for custom entities
- Blizzard Classic API and Wowhead integrations later
